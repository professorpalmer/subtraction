Subtraction is
conditional.

Deletion-first prompting can shift the shape of an agentic refactor—but the effect is task- and model-conditional. In a 240-cell larger-refactor replication, it did not behave like a universal component.

01 / The result

One fixture moved.
One did not.

The shared-normalizer task produced negative deletion-first effects for GPT-5.6 Luna and Grok 4.5. The dead-compatibility-path task produced null or positive effects for every model.

That is evidence for an interaction between task structure and model behavior—not evidence for a portable “D component.”

Interpretation boundaryNo universal mechanism. No significance claim. No priced cost claim.
